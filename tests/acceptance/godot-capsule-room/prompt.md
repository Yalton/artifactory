Build a small Godot 4.7 C# game in this project: a room with a capsule player that moves with WASD.

Also wire up the foundation a bigger game would need. Use every module listed in `MODULES.md` for the job it does, instead of writing that functionality yourself.

Contracts:
- The player node is in the group `player`.
- The main scene is set in `project.godot` (`run/main_scene`).
- The project builds with `dotnet build`.
